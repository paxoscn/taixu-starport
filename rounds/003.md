提炼出的文档缺陷

- D1(高) 没有逐模块 API reference:README 只有功能表和 quick start;22 个模块的签名/字段/示例都得读源码。
- D2(高) 没有 JSON wire contract:ChatChannel 的 dm:<len>:<a><b>、TaskObjective.type、TaskRepeat.kind、SkinCategory 的 other:name、TaskView/ChannelSummary/GameState 字段等,前端无法从文档构造请求/解析状态。
- D3(高) 没有逐方法的错误/原子性矩阵:60+ GameError 变体,哪些方法返回哪些错误、失败是否扣费/发奖/改库存,只能读 game.rs + error.rs。
- D4(中高) 没有状态机/时间语义:任务的新周期/冷却/过期、交易过期与取消、区域 Closed 门禁、房主转移、资源再生、在线心跳。
- D5(中高) 没有锁/并发契约:哪些方法取写锁、read_state guard 为何会死锁、with_state 内能调用什么;第二轮补了警告,但仍没有“方法 → 锁类型”表。
- D6(中) 没有持久化/迁移指南:旧快照缺 version 的行为、版本不匹配如何迁移、GameConfig 不随快照持久化、GameStore 同步 trait 对 Postgres/Redis 的影响。
- D7(中) 没有 NPC 集成契约:完整 prompt/action schema、Reward 嵌套结构、allowed targets、apply_npc_turn 的预校验/提交顺序。
- D8(中) 没有宿主职责清单:鉴权、交易过期扫描、在线清理、快照频率、账号删除/保留、限流。
- D9(中低) GameConfig 无完整参考:README 只展示 2 个字段,实际 12 个。
- D10(中低) 公开字段缺 rustdoc:如 ShopOffer.sold、Region.players、Account.last_seen_ms、ChannelSummary.message_count。
- D11(低) 没有 CHANGELOG/版本化行为变更:第二轮新增 TaskView 字段、GameState.version、channels_for、with_state,只能读 git diff。
- D12(低) 示例不足:除 examples/basic.rs 外,任务四类目标、交易回滚、NPC 动作、区域矩阵、迁移、频道列表等都没有可运行示例。
- D13(低) README 代码块未全部纳入 doctest:F7 曾因示例无法编译而暴露。
